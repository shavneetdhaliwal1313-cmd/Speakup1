# SpeakUp — 120-Day Complete
Upload `index.html`, `style.css`, and `app.js` to the root of your GitHub Pages Speakup1 repository.

Core design:
- 120-day progressive curriculum
- 120-day map and selectable days
- Daily Progress Journal with day/date/activity/score/review
- persistent side notes
- real browser microphone recording + IndexedDB storage
- advanced vocabulary with meanings, alternatives, work examples and spoken/written contexts
- realistic law-firm/workplace scenarios
- five response levels
- feedback on speaking, vocabulary, workplace, reading, writing and networking
- public-domain classic novel reading practice
- typing accuracy tracker
- networking studio
- confidence/presence training
- blogs/guides
- JSON export/import
- local-only data storage
